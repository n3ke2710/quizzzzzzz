# Своя игра

Локальная игра для вечера с друзьями: пульт ведущего на ноутбуке и отдельный экран для проектора. Два обычных раунда по 25 вопросов, финал с девятью темами, специальные клетки и бонусы.

## Сайт на GitHub Pages

- Пульт ведущего: https://n3ke2710.github.io/quizzzzzzz/#/host
- Экран зрителей: https://n3ke2710.github.io/quizzzzzzz/#/screen

Откройте пульт и нажмите «Открыть экран игры». Оба окна должны работать на одном ноутбуке в одном профиле браузера. Сайт загружается через интернет; для игры без интернета используйте локальный запуск ниже.

Вопросы, изображения и текущая игра сохраняются в браузере. Подготовленные на localhost вопросы переносите через «Экспорт» и «Импорт»; результаты текущей партии между локальным запуском и сайтом не переносятся. Сайт не синхронизирует игру между разными компьютерами.

Публикация выполняется автоматически при обновлении `main`: GitHub Actions запускает тесты, собирает `npm run build:pages` и загружает сайт в Pages. В настройках репозитория **Settings → Pages → Source** должен быть выбран **GitHub Actions**. Локальная сборка `npm run build` сохраняет прежние адреса `/host` и `/screen`.

## Установка и запуск

Нужны Node.js 20.19+ или 22.12+ и актуальный Google Chrome. В папке проекта выполните:

```sh
npm install
npm start
```

Откройте [пульт ведущего](http://127.0.0.1:4173/host). Для следующих запусков достаточно `npm start` или двойного нажатия на файл **«Запустить игру.command»** в macOS. Не закрывайте окно терминала во время игры. После установки зависимостей интернет для запуска и игры не нужен; внешние шрифты и изображения не загружаются.

Для разработки: `npm run dev`. Проверки: `npm test` и `npm run build`.

## Два экрана

1. Подключите проектор и включите **расширение рабочего стола** в настройках дисплеев компьютера.
2. В пульте нажмите **«Открыть экран игры»**. Перенесите новое окно на проектор и включите полный экран кнопкой на странице.
3. Оба окна открывайте в одном профиле Chrome, по одному адресу `http://127.0.0.1:4173`. Не используйте режим инкогнито. Если браузер блокирует новое окно, разрешите всплывающие окна для игры или откройте [экран зрителей](http://127.0.0.1:4173/screen) самостоятельно.

Одновременно управляет игрой один пульт. Второй пульт открывается для просмотра; чтобы передать управление, закройте первый и обновите второй. Зрители видят только игровое поле, открытый вопрос, раскрытый ответ, бонусы и рейтинги. Ответы ведущего, ставки и типы ещё закрытых клеток заранее не показываются.

## Подготовка вопросов

При первом запуске открывается демонстрационная игра с 59 готовыми вопросами. Через **«Новая игра»** можно выбрать демонстрацию, пустой шаблон или начать заново с текущими вопросами. Новая игра сбрасывает очки, бонусы и историю, сохраняя названия команд.

В **«Редакторе вопросов»** доступны названия игры, раундов и категорий, текст вопроса и правильного ответа, картинки и типы клеток. Вопрос и ответ могут содержать только текст, только картинку или оба элемента. Поддерживаются PNG, JPEG, WebP и GIF до 6 МБ на картинку. Завершив правки, нажмите **«Сохранить изменения»**. Для уже открытого вопроса отдельно нажмите **«Обновить на экране»** в пульте.

**«Экспорт»** сохраняет вопросы вместе с картинками одним файлом `.quiz.json`. **«Импорт»** проверяет файл и после подтверждения начинает с ним новую игру, обнуляя результаты. Некорректный файл не заменяет текущую игру.

## Проведение игры

- Перед каждым раундом добавьте или переименуйте команды; существующие сохраняют очки, новые начинают с нуля. Счёт можно исправить вручную.
- Выберите команду, которая выбирает клетку, затем саму клетку. Вопрос сначала появляется в предпросмотре ведущего; вывод на проектор выполняется отдельной кнопкой.
- Назначьте отвечающую команду и отметьте правильный или неправильный ответ. Верный ответ добавляет номинал, ошибка снимает его; отрицательный счёт разрешён. После ошибки можно дать слово другой команде. Каждая получает одну попытку, если не использована «Вторая жизнь».
- Во время игры команды выбираются крупными кнопками. При открытом вопросе таблица скрывается, а выбор команды, «Верно», «Неверно», раскрытие ответа и возврат к полю остаются рядом. Уже ответившие команды отключаются, сохраняя своё место.
- Можно раскрыть правильный ответ и закрыть вопрос без победителя. Сыгранная клетка больше не выбирается.
- После последней клетки или досрочного завершения раунда показывается рейтинг от последнего места к первому, с шагом 1,2 секунды. Равные результаты делят место. Доступны показ всех команд сразу, повтор анимации и переход дальше.
- В финале задайте порядок вычёркивания. Команды по очереди убирают восемь из девяти тем. Введите и зафиксируйте ставки всех команд, затем покажите вопрос. Ставка — целое число от нуля, она может превышать счёт команды. После оценки всех ответов нажмите **«Раскрыть ответ»**, затем **«Подвести итоги»** — ставки одновременно прибавляются или снимаются.

## Фишки и бонусы

У каждой клетки один тип, назначаемый в редакторе. Особенность раскрывается до вопроса. В демонстрации раунды различаются:

| Первый раунд | Второй раунд |
| --- | --- |
| **Кот в мешке:** вопрос передаётся сопернику; отвечает только получатель. | **+ на −:** знак всего счёта меняется на противоположный. |
| **И так сойдёт:** до конца раунда ведущий может засчитывать приблизительный ответ по смыслу. | **Обмен очками:** полные счета выбранных соперников меняются местами. |
| **Бронежилет:** отменяет штраф за одну ближайшую итоговую ошибку. | **×2:** весь счёт удваивается, включая отрицательный. |
| **Вторая жизнь:** одна дополнительная попытка после неверного ответа. | **Двойной куш:** активируется перед ответом; верный приносит двойной номинал, ошибка снимает обычный. |

В своём наборе можно распределять типы иначе, но один тип не может встречаться сразу в обоих раундах. В редакторе занятые другим раундом типы недоступны. Чтобы перенести тип, сначала уберите все его назначения из прежнего раунда. Повторы внутри одного раунда разрешены.

Переворот, обмен и ×2 заменяют вопрос и не добавляют номинал клетки. Остальные бонусы выдаются выбравшей клетку команде, после чего играется вопрос. Разовые бонусы накапливаются; на вопрос расходуется максимум одна вторая попытка и одно удвоение награды. Удвоение сохраняется на второй попытке, бронежилет расходуется только при итоговой ошибке. Все оставшиеся бонусы сгорают после раунда.

## Сохранение

Каждое игровое действие сохраняется в браузере до обновления проектора. После перезагрузки игра продолжается с сохранённого состояния. **«История действий»** хранит последние 60 ходов; отмена восстанавливает очки, бонусы и состояние экрана, включая оба счёта после обмена.

Сохранение привязано к этому компьютеру, профилю Chrome и адресу с портом. Очистка данных сайта или удаление профиля браузера удалит сохранённую игру. Регулярно экспортируйте набор вопросов: файл содержит вопросы и картинки, но не текущий счёт и историю партии.
